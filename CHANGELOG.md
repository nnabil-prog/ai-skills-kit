# Changelog

Changes to the Claude Skills Kit that you can see on the site or in the install script.

## 2026-11-17

### ✨ New

- **Public site**: The kit is now on a free public page at https://nnabil-prog.github.io/claude-skills-kit/. You do not need a Claude sign-in to open it.
- **Shorter install command**: The install command is now one line: `curl -fsSL https://nnabil-prog.github.io/claude-skills-kit/install.sh | bash`. Each run gets the newest version of the script.
- **Changelog**: This page lists each change to the kit. The site links to it.

### 🔧 Improvements

- **Script preview**: "Show the script" now shows the same script that the command runs.

## 2026-11-10

- **First version**: The kit was a private claude.ai page. It listed 20 skills, 2 plugins and the skills from your Claude account, with a copy-and-paste install command.
