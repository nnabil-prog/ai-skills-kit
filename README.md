# Claude Skills Kit

Free static site on GitHub Pages: https://nnabil-prog.github.io/claude-skills-kit/

## Update the site

1. Edit `index.html` (the page) or `install.sh` (the install script).
2. Commit and push to `main`. GitHub Pages rebuilds the site in about 1 minute.

The page builds the install command from the URL of `install.sh`, and it loads the script text from that file. Thus you edit the script in one place only.
